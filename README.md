# mmoranpelaez.github.io

This repository no longer contains a website. It exists only to redirect the old
GitHub Pages URLs to their equivalents on <https://mmoranpelaez.com>, which is where
the site now lives.

Kept deliberately:

- `_pages/` -- one redirect stub per old URL, each pointing straight at its final destination
- `_layouts/redirect.html` -- the redirect template
- `sitemap.xml` -- the old URLs, so search engines recrawl them and find the redirects
- `google6ea6143a56cf50e0.html` -- Search Console verification for this property

Do not delete this repository. The redirects need to stay up.
